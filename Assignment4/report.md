# Домашнее задание 4 - student_31

## Данные и сводка

Исходный набор содержит **50 SNV** на GRCh38: chr21 - **7**, chr22 - **43**. Замены: **42 транзиции** (A↔G, C↔T) и **8 трансверсий**. Все исходные записи содержат `QUAL=.`, `FILTER=.`, `INFO=.`; идентификаторы представлены rsID. Точный поиск ClinVar по GRCh38 SPDI вернул записи для **22** вариантов; для остальных 28 по этому запросу совпадений нет.

## Аннотация и выбор транскрипта

Аннотация выполнена Ensembl VEP для GRCh38; частоты взяты из gnomAD Exomes/Genomes v4.1.1. Полный экспорт содержит транскриптные последствия, поэтому один вариант может иметь несколько строк. В сводной таблице основное следствие - самое тяжёлое по Sequence Ontology среди всех VEP-транскриптов; при равном следствии выбирается MANE Select → MANE Plus Clinical → canonical, затем первая строка экспорта. Отдельно приведено следствие MANE Select и список последствий по всем транскриптам.

ClinVar искался по точному GRCh38 SPDI и агрегированные VCV-классификации получены через NCBI E-utilities. Для rs116555717 точная запись **VCV003305447.2** относится к T>C и имеет классификацию **Conflicting classifications of pathogenicity**. Другой VCV с тем же rsID описывает T>G и имеет VUS; эта классификация к T>C не относится. Отсутствие результата SPDI означает отсутствие записи в таком поиске, но не гарантирует отсутствие при другом представлении аллеля. AF gnomAD - популяционная частота, не индивидуальный генотип.

## Три варианта

- **rs4986958 - chr21:33414987 C>G (IFNGR2, ENST00000290219.11).** VEP предсказывает missense и замену **T/R в позиции 58** белка (p.Thr58Arg). Точная запись ClinVar [VCV000036376.19](https://www.ncbi.nlm.nih.gov/clinvar/variation/36376/): **Benign/Likely benign**, несколько submitter без конфликта. gnomAD AF: экзомы 0.0096036; геномы 0.0462722. Белковая замена предсказана, но ClinVar и популяционные данные согласуются с доброкачественной интерпретацией; частота сама по себе не доказывает доброкачественность.
- **rs73200245 - chr21:37072581 G>A (PIGP).** Максимальное следствие VEP - missense на `ENST00000464265.5`, **P/S в позиции 3**. На MANE Select `ENST00000360525.9` последствие intron_variant. Точная ClinVar-запись [VCV001670166.11](https://www.ncbi.nlm.nih.gov/clinvar/variation/1670166/) классифицирована как **Benign**; её транскриптные аннотации включают как intron, так и p.Pro3Ser missense. gnomAD AF: экзомы 0.170734; геномы 0.230553. Это пример того, как представление последствия зависит от транскрипта.
- **rs116555717 - chr22:39231644 T>C (PDGFB, ENST00000331163.11).** VEP предсказывает missense, **Q/R в позиции 145** (p.Gln145Arg). Точная ClinVar-запись [VCV003305447.2](https://www.ncbi.nlm.nih.gov/clinvar/variation/3305447/) имеет **конфликтующие классификации патогенности** (review status: conflicting classifications). gnomAD AF: экзомы 2.87776e-05; геномы 0.000249485. Для того же rsID ClinVar содержит отдельный VUS для T>G; этот аллель отличается от входного T>C и не должен использоваться для его интерпретации. Конфликт точной записи и низкая частота не позволяют сделать однозначный клинический вывод.

## Заключение и ограничения

Самыми интересными выглядят rs73200245 из-за транскриптно-зависимого missense-следствия и rs116555717 из-за конфликта ClinVar при низкой популяционной частоте; rs4986958 - наглядный контраст, где missense-аннотация сочетается с доброкачественной классификацией и заметной частотой. Частоты gnomAD зависят от выборки и покрытия, VEP описывает предсказанные последствия, а ClinVar агрегирует предоставленные классификации разного уровня. Отсутствие результата или частоты нельзя трактовать как отсутствие биологического эффекта. Клиническая оценка требует фенотипа, семейных данных, лабораторной проверки и актуальной экспертной интерпретации.
